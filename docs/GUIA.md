# Guía del Proyecto: Laboratorio 03

Documentación detallada creada para guiar a cualquier compañero en la comprensión y ejecución de este trabajo desde cero.

## Descripción del Proyecto

Este laboratorio aborda la solución al ejercicio práctico del curso, aplicando buenas prácticas de desarrollo y control de versiones. Para clonar el repositorio puedes usar el comando `git clone` en tu terminal.

### Requisitos Previos
* Tener instalado Git en tu sistema.
* Contar con Visual Studio Code.
* Tener acceso a la plataforma GitHub.

---

## Tareas y Avance

Lista de verificación de los requerimientos del laboratorio:

- [x] Configurar el entorno de trabajo y la estructura de carpetas.
- [x] Implementar el código principal del proyecto.
- [ ] Agregar pruebas unitarias adicionales.

---

## Instalación y Uso

### Pasos de Instalación
1. Abrir la terminal de tu preferencia o la terminal integrada de VS Code.
2. Clonar el repositorio ejecutando el comando necesario.
3. Navegar a la carpeta raíz del proyecto.

### Pasos de Ejecución
* Abrir el archivo principal dentro de tu editor de código.
* Verificar los recursos cargados en la carpeta correspondiente.
* Ejecutar el script o revisar la documentación renderizada.
